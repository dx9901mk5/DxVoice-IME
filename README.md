# PixelVoice-IME | Pixel 語音輸入法仿生

> **獨立的 Android 語音輸入法 APK（仿生 Google Pixel Assistant Voice Typing），結合離線語音檔案管理、自主收音判定、Gemini 語意修潤與自動標點回填，以及自動切回原輸入法與 GitHub 自動更新。**

## ✨ 核心特色

1. **切換即自主收音與判定**：切換至 `PixelVoice 語音輸入法` 後，立即自動啟動語音接收與停頓判定（密碼欄位自動防護略過）。
2. **Gemini 自動修正與標點貼回**：支援「極速文字修潤」與「多模態音訊精修」雙模式，自動修正同音異字、去除口語贅詞、補齊標點符號並自動貼回輸入框（附「復原原文」快捷鍵）。
3. **記憶並自動切回原輸入法**：說完貼回後自動呼叫系統機制立刻切回先前使用的鍵盤（Gboard、超注音、三星鍵盤等），亦提供一鍵手動切回按鈕。
4. **仿 Google 語音輸入法離線語系庫**：內建 60+ 語系與地區變體清單（繁中/粵語/簡中/日/韓/英/歐/東南亞等），支援離線模型下載、解壓縮與空間管理。
5. **跟隨鍵盤懸浮語音捷徑球**：使用其他鍵盤時自動浮現精巧（`28dp`）懸浮麥克風球，點擊免跳選單一鍵直接啟動本輸入法收音，並針對摺疊機外螢幕與內螢幕獨立記憶位置。
6. **輸入法直達設定、雲端備份與 GitHub 自動更新**：支援雙欄自適應介面、Pixel 動態色彩／橘色灰黑底雙主題、Google 雲端硬碟一鍵備份還原，以及 GitHub Releases 自動檢測下載更新。
